# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

---

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please follow these steps:

1. **Do not** open a public GitHub issue.
2. Send an email to **timotnagy25@gmail.com** with details about the vulnerability, steps to reproduce it, and potential risks.
3. You will receive an acknowledgment response within 48 hours.
4. Once the issue is resolved and tested, a new release with the patch will be published.
